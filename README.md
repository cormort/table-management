# 會議室與展廳座位配置管理工具

單檔零相依的視覺化會議室與展廳座位配置工具，支援防重疊版型、拖曳編輯、教室矩陣、階梯大講堂弧形排位與向量 SVG / Excel CSV 匯出。

## 線上使用 (GitHub Pages)

👉 https://cormort.github.io/table-management/

## 主要功能

- **12 種內建座位版型**：首長會議（U 型）、委員會議（口字型）、董事會、雙邊談判、視訊會議、教育訓練、考試／甄試、工作坊分組、簡報／記者會、論壇／座談會、大型講堂、圓桌會議／餐敘，提供即時 SVG 預覽與搜尋篩選。
- **防重疊幾何與即時檢測**：統一依據桌型與旋轉席位尺寸計算最小淨距，並以分離軸定理（SAT）即時偵測與標示重疊席位。
- **快速生成器與批次排位**：支援教室行列矩陣生成、階梯大講堂弧形同心圓生成、名單批次匯入與自動防重疊排列。
- **場地結構與匯出**：支援隔間牆、單／雙開門、立柱與講台拖曳配置；支援 JSON 專案備份還原、SVG 向量圖與 UTF-8 BOM CSV 席次清冊匯出。
- **操作體驗**：支援多步復原（`Ctrl+Z` / 工具列復原）、畫布縮放與 `localStorage` 自動暫存。
